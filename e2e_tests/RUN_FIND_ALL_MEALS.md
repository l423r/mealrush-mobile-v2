# Инструкция по запуску теста поиска всех приемов пищи

## Описание теста

Тест `test_find_all_meals.py` выполняет:
1. Логин под пользователем `qweqwe@gmail.com` / `qweqweqwe`
2. Переход на главный экран
3. Поиск всех 6 приемов пищи тремя методами:
   - **METHOD 1**: Поиск через бейдж (основной метод - простой и быстрый)
   - **METHOD 2**: Детальный поиск через карточки (для детального анализа)
   - **METHOD 3**: Детальный поиск по типам приемов пищи
4. Проверка что все приемы пищи найдены

**Рекомендация**: Для быстрого определения количества приемов пищи используйте бейдж. Для детального анализа используйте поиск по карточкам.

## Предварительные условия

1. **Эмулятор/устройство должно быть запущено**
2. **Приложение должно быть установлено**
3. **На главном экране должно быть 6 приемов пищи** (после логина)

## Подготовка

### Вариант 1: Через bat-скрипт (РЕКОМЕНДУЕТСЯ)

Просто запустите файл `run_find_all_meals.bat`:

```bash
cd mealrush-mobile-v2/e2e_tests
run_find_all_meals.bat
```

Или двойным кликом по файлу `run_find_all_meals.bat` в проводнике Windows.

### Вариант 2: Через командную строку (Windows)

```bash
cd mealrush-mobile-v2/e2e_tests
python -m pytest tests/test_find_all_meals.py::TestFindAllMeals::test_find_all_meals_on_main_screen -v -s
```

### Вариант 3: Через существующий скрипт

Модифицируйте `run_tests.bat` или `run_tests.sh` для запуска только этого теста:

```bash
# В run_tests.bat добавьте:
python -m pytest tests/test_find_all_meals.py::TestFindAllMeals::test_find_all_meals_on_main_screen -v -s
```

## Запуск через pytest напрямую

```bash
# Из директории e2e_tests
pytest tests/test_find_all_meals.py -v -s

# Или с указанием конкретного теста
pytest tests/test_find_all_meals.py::TestFindAllMeals::test_find_all_meals_on_main_screen -v -s

# С подробным выводом
pytest tests/test_find_all_meals.py -v -s --tb=long

# С сохранением скриншотов
pytest tests/test_find_all_meals.py -v -s --screenshot-on-failure
```

## Параметры запуска

- `-v` - подробный вывод
- `-s` - показывать print statements
- `--tb=short` - короткий traceback при ошибках
- `--tb=long` - полный traceback при ошибках
- `-k "find_all"` - запустить только тесты с "find_all" в названии

## Ожидаемый результат

Тест должен:
1. Успешно залогиниться
2. Найти главный экран
3. Найти все 6 приемов пищи через:
   - Бейдж (если доступен)
   - Поиск карточек
   - Детальный поиск по типам
4. Вывести подробную статистику
5. Пройти все проверки

## Логи

Тест выводит подробные логи:
- `[STEP 1]` - шаги логина
- `[STEP 2]` - проверка главного экрана
- `[STEP 3]` - поиск приемов пищи
- `[METHOD 1]` - поиск через бейдж
- `[METHOD 2]` - поиск через карточки
- `[METHOD 3]` - детальный поиск по типам

## Скриншоты

Скриншоты сохраняются в:

## Устранение проблем

### Проблема: Тест не находит приемы пищи

1. Убедитесь что на главном экране действительно 6 приемов пищи
2. Проверьте что главный экран полностью загрузился
3. Попробуйте увеличить таймауты в тесте

### Проблема: Ошибка логина

1. Проверьте что пользователь `qweqwe@gmail.com` существует
2. Проверьте правильность пароля `qweqweqwe`
3. Убедитесь что приложение запущено и готово к работе

### Проблема: Главный экран не загружается

1. Увеличьте время ожидания в тесте
2. Проверьте что приложение не зависло
3. Попробуйте перезапустить приложение перед тестом
