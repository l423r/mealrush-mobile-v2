# Как остановить тесты

## Остановка тестов pytest

### Windows (Git Bash / CMD / PowerShell):
Нажмите **`Ctrl + C`** в терминале, где запущены тесты.

Если не помогло, нажмите **`Ctrl + C`** дважды (принудительная остановка).

### Linux/Mac:
Нажмите **`Ctrl + C`** в терминале.

Если не помогло:
- **`Ctrl + C`** дважды - принудительная остановка
- **`Ctrl + Z`** - приостановка процесса (затем `kill %1` для завершения)

## Что происходит при остановке:

1. Текущий тест будет прерван
2. Скриншоты до момента остановки будут сохранены
3. Driver будет закрыт автоматически (через fixture teardown)
4. Appium Server продолжит работать (его нужно остановить отдельно, если нужно)

## Остановка Appium Server:

Если нужно остановить Appium Server:
- В терминале где запущен Appium нажмите **`Ctrl + C`**

## Если тесты зависли:

1. Попробуйте **`Ctrl + C`** дважды
2. Если не помогает, закройте терминал
3. Проверьте процессы: `tasklist | findstr python` (Windows) или `ps aux | grep pytest` (Linux/Mac)
4. Убейте процесс вручную если нужно
