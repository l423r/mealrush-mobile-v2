# Детальное логирование поиска элементов

## Включение детального логирования

Для включения детального логирования всех поисков элементов установите переменную окружения:

```bash
# Windows (PowerShell)
$env:DETAILED_ELEMENT_LOGGING="true"
pytest tests/test_meal_creation.py -v -s

# Windows (CMD)
set DETAILED_ELEMENT_LOGGING=true
pytest tests/test_meal_creation.py -v -s

# Linux/Mac
export DETAILED_ELEMENT_LOGGING=true
pytest tests/test_meal_creation.py -v -s
```

## Что логируется

### Автоматически (всегда):
- ✗ **Неудачные поиски** - элементы, которые не были найдены (с таймаутом)
- ⚠ **Долгие поиски** - поиски, которые заняли больше 2 секунд

### При включенном DETAILED_ELEMENT_LOGGING:
- ✓ **Успешные поиски** - все найденные элементы с временем поиска
- [MULTIPLE] **Множественные локаторы** - какие локаторы пробуются, какой сработал
- [TRANSITION] **Переходы между экранами** - ожидание загрузки экранов
- [MAIN_PAGE] **Проверка главного экрана** - какие индикаторы проверяются

## Формат логов

```
[FIND] Ищем элемент: xpath: //*[@text='Расписание' or contains(@text, 'Расписание')] (timeout=10s)
[FIND] ✓ Найден за 234ms: xpath: //*[@text='Расписание' or contains(@text, 'Расписание')]

[FIND] [MULTIPLE] Пробуем 5 локаторов (timeout=10s)
[FIND] [MULTIPLE] Попытка 1/5: accessibility_id: add_meal_button
[FIND] [MULTIPLE] ✓ Успех на попытке 1 за 156ms: accessibility_id: add_meal_button

[FIND] ✗ НЕ найден за 20000ms (timeout=20s): xpath: //*[@text='Несуществующий элемент']
```

## Анализ логов

### Проблемы, на которые обращать внимание:

1. **Долгие поиски (>2s)**:
   ```
   [FIND] ⚠ Долгий поиск (5234ms): xpath: //*[@text='Расписание'...]
   ```
   → Элемент находится, но долго. Возможно, нужно оптимизировать локатор.

2. **Неудачные поиски**:
   ```
   [FIND] ✗ НЕ найден за 20000ms (timeout=20s): xpath: //*[@text='Элемент']
   ```
   → Элемент не существует или локатор неправильный. Нужно проверить/исправить.

3. **Множественные локаторы - все неудачны**:
   ```
   [FIND] [MULTIPLE] ✗ Все 5 попыток не удались за 5000ms
   ```
   → Все локаторы неверны. Нужно пересмотреть стратегию поиска.

4. **Множественные локаторы - успех на последней попытке**:
   ```
   [FIND] [MULTIPLE] Попытка 1/5: accessibility_id: button
   [FIND] [MULTIPLE] ✗ Попытка 1 не удалась
   ...
   [FIND] [MULTIPLE] ✓ Успех на попытке 5 за 4500ms: xpath: //*[@text='Button']
   ```
   → Первые локаторы не работают. Нужно переставить порядок или удалить неработающие.

## Примеры оптимизации

### Пример 1: Долгий поиск главного экрана

**До:**
```
[MAIN_PAGE] Проверка загрузки главного экрана (timeout=10s)
[MAIN_PAGE] 'Расписание' не найдено, проверяем другие индикаторы...
[MAIN_PAGE] Проверка индикатора 1/5
[FIND] ✗ НЕ найден за 2000ms: xpath: //*[@text='Приемы пищи'...]
[MAIN_PAGE] Проверка индикатора 2/5
[FIND] ✗ НЕ найден за 2000ms: xpath: //*[@text='Сегодня'...]
...
[MAIN_PAGE] ✓ Найден индикатор 4
```

**Проблема:** Проверяются неработающие локаторы, тратится время.

**Решение:** Удалить неработающие локаторы из `MAIN_SCREEN_INDICATORS` или переставить порядок.

### Пример 2: Множественные локаторы - все пробуются

**До:**
```
[FIND] [MULTIPLE] Пробуем 5 локаторов
[FIND] [MULTIPLE] Попытка 1/5: accessibility_id: add_meal_button
[FIND] [MULTIPLE] ✓ Успех на попытке 1 за 156ms
```

**Хорошо:** Первый локатор работает быстро.

**Если бы:**
```
[FIND] [MULTIPLE] Попытка 1/5: accessibility_id: add_meal_button
[FIND] [MULTIPLE] ✗ Попытка 1 не удалась
[FIND] [MULTIPLE] Попытка 2/5: xpath: //*[@content-desc='Добавить прием пищи']
[FIND] [MULTIPLE] ✓ Успех на попытке 2 за 1200ms
```

**Проблема:** Первый локатор не работает, нужно исправить или удалить.

## Рекомендации

1. **Включите логирование** для проблемных тестов:
   ```bash
   DETAILED_ELEMENT_LOGGING=true pytest tests/test_meal_creation.py::TestMealCreation::test_12 -v -s
   ```

2. **Ищите паттерны**:
   - Элементы, которые всегда не находятся → удалить/исправить локаторы
   - Элементы, которые находятся на последней попытке → переставить порядок
   - Долгие поиски (>2s) → оптимизировать локаторы или уменьшить таймаут

3. **Оптимизируйте локаторы**:
   - Используйте `accessibility_id` вместо `xpath` где возможно (быстрее)
   - Упрощайте XPath выражения
   - Удаляйте неработающие локаторы из множественных списков

4. **Анализируйте статистику**:
   - Смотрите на итоговую статистику профилирования
   - Обращайте внимание на операции с высоким средним временем
   - Ищите операции, которые выполняются много раз
