# Исправление иконки уведомлений для Android

## Проблема
Иконка приложения не отображалась в уведомлениях на Android устройствах.

## Решение
Создана монохромная (белая) иконка уведомлений для всех плотностей экрана Android.

## Что было сделано

1. **Создан скрипт генерации иконок**: `scripts/generate_notification_icon.py`
   - Преобразует цветную иконку в монохромную (белую на прозрачном фоне)
   - Генерирует иконки для всех плотностей: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi

2. **Сгенерированы иконки уведомлений**:
   - `drawable-mdpi/notification_icon.png` (24x24)
   - `drawable-hdpi/notification_icon.png` (36x36)
   - `drawable-xhdpi/notification_icon.png` (48x48)
   - `drawable-xxhdpi/notification_icon.png` (72x72)
   - `drawable-xxxhdpi/notification_icon.png` (96x96)

3. **Проверена конфигурация**:
   - AndroidManifest.xml правильно настроен с ссылками на `@drawable/notification_icon`
   - Цвет уведомлений настроен: `@color/notification_icon_color` (#4CAF50)

## Требования Android для иконок уведомлений

Android 5.0+ требует:
- **Монохромные иконки** (белые на прозрачном фоне)
- **Размер**: 24dp (базовый размер)
- **Формат**: PNG с прозрачностью

## Как пересобрать приложение

После создания иконок необходимо пересобрать нативный код:

### Вариант 1: Через Expo (рекомендуется)
```bash
npx expo prebuild --clean
```

### Вариант 2: Через Gradle
```bash
cd android
./gradlew clean
cd ..
```

### Затем соберите и установите приложение:
```bash
# Для разработки
npx expo run:android

# Или через Expo Go (если используете)
npx expo start
```

## Проверка работы

1. Установите приложение на устройство
2. Отправьте тестовое уведомление
3. Проверьте, что иконка отображается в статус-баре

## Регенерация иконок

Если нужно обновить иконки уведомлений:

```bash
python scripts/generate_notification_icon.py assets/icon.png --project-root .
```

## Дополнительная информация

- Иконки уведомлений отличаются от иконки приложения
- Они должны быть монохромными для лучшей видимости в статус-баре
- Цвет иконки задается через `notification_icon_color` в colors.xml
- Для Android 13+ могут быть дополнительные требования
