# Идеи для дальнейшего развития функционала друзей

Этот документ содержит идеи и концепции для расширенного функционала друзей, которые можно реализовать после MVP.

## 1. Социальные челленджи и соревнования

### 1.1 Еженедельные челленджи
- **Типы челленджей:**
  - "Кто съест больше белка" - соревнование по количеству белка за неделю
  - "Кто лучше соблюдает калории" - минимальное отклонение от цели по калориям
  - "Кто больше шагов" - интеграция с фитнес-трекерами
  - "Самый разнообразный рацион" - наибольшее количество разных продуктов
  - "Регулярность питания" - кто чаще записывает приемы пищи

- **API эндпоинты:**
  ```
  POST /my-food/friends/challenges
  GET /my-food/friends/challenges
  GET /my-food/friends/challenges/{challengeId}
  POST /my-food/friends/challenges/{challengeId}/join
  GET /my-food/friends/challenges/{challengeId}/leaderboard
  GET /my-food/friends/challenges/{challengeId}/progress
  DELETE /my-food/friends/challenges/{challengeId}
  ```

- **Структура данных:**
  ```typescript
  interface Challenge {
    id: number;
    type: 'PROTEIN' | 'CALORIES' | 'STEPS' | 'VARIETY' | 'REGULARITY';
    title: string;
    description: string;
    startDate: string;
    endDate: string;
    participants: ChallengeParticipant[];
    leaderboard: LeaderboardEntry[];
    status: 'ACTIVE' | 'COMPLETED' | 'CANCELLED';
  }
  ```

### 1.2 Лидерборды
- Рейтинг участников в реальном времени
- Визуализация прогресса каждого участника
- Награды и достижения за победы
- История прошлых челленджей

### 1.3 Групповые челленджи
- Создание челленджей для группы друзей (3-5 человек)
- Командные соревнования
- Общий прогресс группы

## 2. Мотивация и поддержка

### 2.1 Комментарии и реакции на приемы пищи
- **Лайки:**
  ```
  POST /my-food/friends/interactions/meal/{mealId}/like
  DELETE /my-food/friends/interactions/meal/{mealId}/like
  GET /my-food/friends/interactions/meal/{mealId}/likes
  ```

- **Комментарии:**
  ```
  POST /my-food/friends/interactions/meal/{mealId}/comment
  GET /my-food/friends/interactions/meal/{mealId}/comments
  PUT /my-food/friends/interactions/comment/{commentId}
  DELETE /my-food/friends/interactions/comment/{commentId}
  ```

- **Реакции:** 👍, 💪, ❤️, 🎉, 🔥
- Мотивационные сообщения: "Отличный завтрак!", "Ты на правильном пути!"

### 2.2 Напоминания от друзей
- Друзья могут отправлять напоминания: "Не забудь пообедать!"
- Push-уведомления о напоминаниях
- Настройка частоты напоминаний

### 2.3 Дневник поддержки
- Друзья могут оставлять записи с мотивацией
- История поддержки
- Персональные сообщения поддержки

## 3. Сравнительная аналитика

### 3.1 Сравнение с другом
- **API эндпоинты:**
  ```
  GET /my-food/friends/{friendId}/compare?period={week|month}
  GET /my-food/friends/{friendId}/compare/metrics?metrics=calories,protein,weight
  ```

- **Метрики для сравнения:**
  - Калории (средние, общие)
  - Макронутриенты (белки, жиры, углеводы)
  - Вес и прогресс по весу
  - Регулярность питания
  - Популярные продукты

- **Визуализация:**
  - Совместные графики
  - Процентные сравнения
  - Инсайты: "Ты на 15% ближе к цели, чем неделю назад"

### 3.2 Сравнение группы
- Средние показатели по группе друзей
- Позиция пользователя в группе
- Групповые тренды

### 3.3 Инсайты
- "Твои друзья едят больше овощей в обед"
- "Средний вес группы снизился на 2 кг за месяц"
- Персональные рекомендации на основе сравнения

## 6. Уведомления и активности

### 6.1 Push-уведомления
- **Типы уведомлений:**
  - `FRIEND_REQUEST_RECEIVED` - получен запрос в друзья
  - `FRIEND_REQUEST_ACCEPTED` - запрос принят
  - `FRIEND_MEAL_ADDED` - друг добавил прием пищи (если есть право просмотра)
  - `FRIEND_GOAL_PROGRESS` - друг достиг цели
  - `CHALLENGE_INVITATION` - приглашение в челлендж
  - `CHALLENGE_LEADERBOARD_UPDATE` - обновление лидерборда
  - `COMMENT_ON_MEAL` - комментарий к приему пищи
  - `LIKE_ON_MEAL` - лайк на прием пищи
  - `FRIEND_REMINDER` - напоминание от друга

- Настройки уведомлений для каждого типа
- Группировка уведомлений

### 6.2 Лента активности друзей
- Опциональная лента активности друзей
